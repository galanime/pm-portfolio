python -m http.server 8080

访问 `http://localhost:8080/`。现有 GitHub Pages 结构保持兼容：`index.html` 位于根目录。

## 纵向滚动背景

背景是一幅随文档滚动的连续纵向画面，使用贯穿全页的弯曲光带、细线、圆环节点与分段蓝青色光晕。主光带从顶部延伸到底部，位置属于文档而非固定视口；光点随阅读位置沿路径移动，光晕以轻微视差补充纵深。背景绝不拦截点击或盖住内容；图片、肖像和案例卡片保持原布局与遮挡保护。系统减少动效时关闭脉冲与视差，保留静态背景。展开案例、筛选和窗口变化会更新路径尺寸，不持续绘制长画布。
